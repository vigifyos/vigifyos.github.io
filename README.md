# VigifyOS

Portal oficial de acesso ao **VigifyOS**, sistema de gerenciamento de Ordens de Serviço desenvolvido para centralizar e otimizar o fluxo operacional entre gestores e equipes técnicas.

## Sobre o VigifyOS

O VigifyOS oferece uma interface integrada para gerenciamento e execução de Ordens de Serviço, permitindo que gestores e técnicos acompanhem suas atividades através de uma experiência centralizada e adaptada aos diferentes ambientes de utilização.

O sistema está disponível para acesso via navegador e também através do aplicativo **VigifyOS para Android**, destinado ao uso das equipes técnicas em campo.

## Portal

Este repositório é destinado exclusivamente ao **portal web de acesso ao VigifyOS**, responsável por disponibilizar o ponto de entrada para o sistema.

A aplicação principal e sua implementação não são mantidas neste repositório.
